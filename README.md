# WebMap Overlay

Stormworks の画面に WebMap を重ねて表示する Windows 向けアプリです。WebMap に対応したサーバーと、登録済みのユーザー情報が必要です。

使い方
------
1. アプリを起動し、「一覧更新」で自分のユーザー名を選びます。
2. 表示方式を選び、「オーバーレイ開始」を押します。
3. Stormworks をアクティブにするとマップが表示されます。

通常オーバーレイは別ウィンドウで表示し、排他的フルスクリーンには対応しません。ゲーム内描画は DLL をゲームに読み込みます。ゲームのクラッシュやセキュリティソフトの警告が起きる可能性があるため、開始時の確認を読んで選択してください。

無変換キーで表示を切り替え、Z/X で地図の拡大・縮小ができます。表示位置やサイズ、キーは設定画面で変更できます。表示されない場合は、ゲームの起動状態、ユーザー選択、WebMap の接続状態を確認してください。

Stormworks に合わせた自動起動は Windows のタスクスケジューラを使用します。登録や削除には管理者確認が必要になる場合があります。アンインストール時は保存設定も削除されます。

更新
----
起動時と6時間ごとに更新を確認します。署名を確認した更新のみを案内し、ダウンロード後と適用直前にも検証します。ゲーム内描画の DLL が使用中の場合はゲーム終了後に適用します。配布元: https://github.com/sk7z-xyz/WebMapOverlay/releases

----
